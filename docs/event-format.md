# 스마트 반사경 접근 이벤트 형식 (2단계)

2단계에서 앱이 받는 이벤트의 형식입니다. 이 저장소에는 형식, 좌우 판정, 합성 생성기만 있으며, 키트의 하드웨어와 통신 구현은 포함하지 않습니다. 구현은 `core/.../SmartMirror.kt`입니다.

## 필드

| 필드 | 형식 | 설명 |
|---|---|---|
| `intersectionId` | 문자열 | 교차로 DB의 `id` |
| `approachRoadId` | 문자열 | 상대 차량이 들어오는 진입도로. DB `approaches[].roadId`와 일치 |
| `approachState` | `APPROACHING` · `RECEDING` · `NONE` | 상대 차량이 교차로로 접근 중인지 |
| `detectedAtMs` | 정수(ms) | 감지 시각 |
| `sensorState` | `OK` · `FAULT` | 센서 상태 |

예시 (합성):

```json
{"intersectionId": "SAMPLE-SS-01", "approachRoadId": "W", "approachState": "APPROACHING", "detectedAtMs": 1762851600000, "sensorState": "OK"}
```

## 운전자 기준 좌우 판정

1. 자차가 들어오는 도로를 찾습니다. 진행 방위의 반대쪽(진행 방위 + 180°)에 가장 가까운 진입도로입니다.
2. 이벤트의 진입도로가 자차 도로와 같으면 제외합니다.
3. `각도차 = 접근도로 방위 − 자차 진행 방위`를 −180° 초과 180° 이하로 정규화합니다.
4. −135° 이상 −45° 이하는 **왼쪽**, 45° 이상 135° 이하는 **오른쪽**입니다. 경계값을 포함하며, 그 밖은 판정하지 않습니다.
5. `approachState`가 `APPROACHING`이 아니거나 `sensorState`가 `FAULT`이면 경보하지 않습니다.

진입도로 방위는 교차로 중심에서 그 도로가 뻗은 방향입니다. 예: 남쪽에서 북진(진행 방위 0°)할 때 서쪽 도로(270°)는 각도차 −90°로 왼쪽입니다.

## 정해지지 않은 것

- 전송 경로(현장 Wi-Fi, 서버 경유, 직접 연결)와 인증 방식
- 이벤트 유효시간과 통신 끊김 판단 시간
- 키트와 차량 사이 시계 동기화 방법

위 항목은 실제 키트 시험으로 정하며, 이 저장소의 범위가 아닙니다.
