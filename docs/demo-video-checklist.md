# 시연 영상 촬영 체크리스트 (30~60초)

에뮬레이터에서 실제로 앱을 실행한 화면을 녹화합니다. 목업 영상과 구분되도록, 이 영상은 "에뮬레이터 실행 화면 + 합성 입력"임을 분명히 보여 줍니다.

## 촬영 전

- [ ] Pleos Connect Emulator v2.1.0 이상, Cold boot로 실행
- [ ] 앱 설치 후 한 번 실행해 음성이 나오는지 확인 (한국어 TTS)
- [ ] 화면 맨 위 노란 띠 "합성 입력 · 실제 차량·센서 신호 아님"이 보이는지 확인. 앱에 고정되어 있어 따로 넣을 필요 없음
- [ ] 녹화 프로그램의 소리 녹음이 켜져 있는지 확인
- [ ] 화면과 파일 이름에 실명, 개인 이메일, 계정 이름이 나오지 않는지 확인
- [ ] 녹화 도구: Android Studio의 Running Devices 녹화, 에뮬레이터 Extended controls의 Record, 또는 Windows `Win + G`

## 촬영 순서 (약 45초)

| 시간 | 화면 | 확인할 것 |
|---|---|---|
| 0~5초 | 앱 첫 화면 | 앱 이름, "합성 입력" 띠 |
| 5~25초 | `s01_night_basic` 실행 | 거리 숫자가 120m 부근에서 줄어듦, 50m에서 음성 1회, 통과 후 "앞쪽 등록 교차로 없음" |
| 25~33초 | `s02_day_no_light` 실행 | 기록에 "생략(주간·맑음)", 음성 없음 |
| 33~45초 | `s06_cluster` 실행 | 교차로 2곳 중 음성 1회, 두 번째는 "묶음 안내에 포함" |

시간이 남으면 `s04_slow_turn_signal`(저속+방향지시등 안내)을 추가합니다. `s04`는 36초가 걸리므로 영상이 60초를 넘지 않게 편집합니다.
