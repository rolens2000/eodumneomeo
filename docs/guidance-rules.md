# 1단계 안내 규칙

숫자는 모두 실차 검증 전 목표값이며 `data/guidance.properties`에서 바꿉니다. 구현은 `core/.../GuidanceEngine.kt`입니다.

## 규칙 표

| 순서 | 규칙 | 설정 키 | 기본값 | 결과 |
|---|---|---|---|---|
| 0 | 신호 교차로는 대상에서 뺀다 | - | - | 판정 없음 |
| 0 | 진행 방향 앞 교차로만 본다 | `ahead.coneDeg`, `ahead.lookaheadM` | 30°, 200m | 판정 없음 |
| 0 | 교차로까지 거리가 안내 거리를 처음 넘어서는 순간 한 번만 판정한다 | `announce.distanceM` | 50m | - |
| 1 | 같은 교차로는 한 번 주행에 1회 | - | - | 판정 없음 |
| 2 | 브레이크를 밟고 있으면 생략 | - | - | `SKIP_BRAKE` |
| 3 | 전조등 켜짐 또는 와이퍼 작동일 때만 안내. 사고다발 교차로는 항상 | - | - | `SKIP_CONDITION` |
| 4 | 시속 20km 이상일 때만 안내. 방향지시등이 켜져 있으면 속도 무관 | `announce.minSpeedKph` | 20 | `SKIP_SPEED` |
| 5 | 안내한 교차로에서 150m 안의 다른 앞쪽 교차로는 묶어 다시 안내하지 않음 | `cluster.radiusM` | 150m | `SKIP_CLUSTERED` |
| - | 모두 통과하면 안내 | `announce.text` | 아래 문구 | `ANNOUNCE` |

안내 문구: "전방에 시야가 제한된 비신호 교차로가 있습니다. 서행하세요."

## 정의

- **진행 방향 앞:** 자차에서 교차로를 바라본 방위와 자차 진행 방위의 차가 ±30° 이내이고, 거리가 200m 이내.
- **처음 넘어서는 순간:** 직전 위치에서는 50m보다 멀고 현재 위치에서는 50m 이하인 시점. 앱을 50m 안에서 처음 켜면 그 교차로는 판정하지 않습니다.
- **한 번 주행:** 기어가 P로 바뀌면 새 주행으로 보고 1회 안내 기록을 지웁니다.
- **지나친 안내 취소:** 안내한 교차로가 자차 진행 방향 기준 90°보다 뒤로 가면 `Cancel`을 보냅니다(`passed.angleDeg`). 재생 중이면 멈추고 대기 중이면 지웁니다.
- **음성:** `SpeechQueue`가 한 번에 한 문장만 재생합니다.
- **판정 시점이 한 번인 이유:** 브레이크·속도 조건은 50m를 넘는 순간의 상태로 판정하며, 이후 조건이 바뀌어도 다시 판정하지 않습니다. 실차 시험에서 조정할 수 있습니다.
